- **F13 | I3** — Hydraulic model workflow: Rainfall + physical environment (topography, land use, drainage network) + physical equations (hydrology, hydraulics) → simulation software TUFLOW → flood level on a 2D grid.   Locator: S02 | PDF p.11–12 | Diagrams "Hydraulic model simulation" / "Hydraulic model simulation + machine learning"
  Anchor: "Simulation software (TUFLOW)"
  Context: Input = rainfall; output = flood level on 2D grid (same as hydraulic model). Grid resolution not given.
